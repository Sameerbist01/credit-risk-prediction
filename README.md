# Credit Risk Prediction

## Overview
A Machine Learning project that predicts credit risk using a trained classification model.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- FastAPI

## Features
- Data preprocessing
- Missing value handling
- Numerical feature scaling
- Categorical feature encoding
- Machine Learning prediction
- API integration

## Project Structure
```text
model/
├── main_py.py
├── credit_risk_model.pkl
├── requirements.txt
├── README.md
└── .gitignore
```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main_py.py
```
